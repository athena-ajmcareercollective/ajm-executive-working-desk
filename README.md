# AJM Career Collective | Executive Working Desk

This private repository is the **editable project home** for the AJM Executive Working Desk. It is intended to let ChatGPT and Codex work on the same approved website without recreating it each time.

## Existing Working Desk is the visual master

**Approved existing site:** https://athena-working-desk.ajm-career-c-9625.chatgpt.site/

**Design decision (October 31, 2026):** Preserve the original website's visual design, navigation, colors, typography, card language, spacing, and overall feel. Bring in the improved V2 content and useful interactions **without redesigning the site**. The alternate V2 redesign was not approved and is not the design reference.

> The existing site's original HTML/CSS source is not in this repository yet. Do not approximate or replace its styling and claim visual fidelity. First recover the original editable source or establish a visual reference that can be compared closely. Do not modify the current published site as part of setting up this repository.

## What belongs in the Working Desk

- Daily Brief: no more than three immediate outcomes and only decisions Athena actually needs to make.
- Weeks of November 2 and November 9: session preparation and next meaningful actions.
- **November goals**: five outcomes, latest substantive updates, owner, status, next action, blocker, and direct source link.
- **December goals**: five planned continuations with unconfirmed items clearly marked as proposed.
- Client Coverage, Executive Office, Client Delivery, New Business, Editorial Studio, Rebrand + Library, and Dashboards + Files: preserve the original views while improving the *quality* of each summary, not the quantity of records.
- Editable notes and status controls, with clear saving/export behavior and no suggestion of automatic synchronization where none has been proven.

## Source-of-truth boundaries

- **Asana** owns project tasks and execution.
- **Google Workspace** owns client deliverables, source documents, and operational dashboards.
- **This Working Desk** is the calm executive view; it links to existing work and summarizes recent changes without duplicating full trackers.
- **GitHub** holds the website source and approved change history. Private GitHub is not the same as a private deployed website; any future hosting needs access controls appropriate to client/internal information.
- Updates currently require manual reconciliation. Never present locally saved notes as synchronized to Google or Asana.
